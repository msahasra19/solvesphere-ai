🎯 FOLLOW THESE 5 SIMPLE STEPS:

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Install Dependencies                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  Open terminal in the solvesphere-ai folder and run:
  
  npm install


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Get Your FREE Gemini API Key                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Visit: https://makersuite.google.com/app/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Copy the API key (starts with "AI...")
  
  ⭐ NO CREDIT CARD REQUIRED - Completely FREE!


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Setup Environment Variables                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Copy .env.example to .env:
     
     Windows: copy .env.example .env
     Mac/Linux: cp .env.example .env
  
  2. Open .env file and update these values:
  
     GEMINI_API_KEY=paste_your_api_key_here
     JWT_SECRET=change_this_to_any_random_string
     MONGODB_URI=mongodb://localhost:27017/solvesphere-ai


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: Setup MongoDB                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  OPTION A - Local MongoDB (Recommended for Development):
  
    1. Download from: https://www.mongodb.com/try/download/community
    2. Install and start MongoDB service
    3. Verify it's running: mongosh
  
  OPTION B - MongoDB Atlas (Cloud - Free Tier):
  
    1. Create account: https://www.mongodb.com/cloud/atlas
    2. Create free cluster
    3. Get connection string
    4. Update MONGODB_URI in .env file


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: Run the Application                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  npm run dev
  
  Then open: http://localhost:3000

🐛 COMMON ISSUES:

  ❌ "MongoDB connection error"
     → Make sure MongoDB is running: mongosh
     → Check MONGODB_URI in .env file
  
  ❌ "Gemini API error"
     → Verify API key is correct in .env
     → Check no extra spaces around the key
     → Ensure API key is enabled at Google AI Studio
  
  ❌ "Port 3000 already in use"
     → Kill the process using port 3000
     → Or use different port: npm run dev -- -p 3001
